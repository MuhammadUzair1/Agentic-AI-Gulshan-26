# 📘 Module 1: Foundations

**Goal:** Build a strong base in Python, then use it to create your **first AI agent**.

---

## 🧩 What We'll Cover

### Part A: Python 🐍
| Topic | What you'll learn |
|---|---|
| Python Basics I & II | Variables, input/output, data types, conditions, loops, functions |
| Advanced Python I & II | Writing cleaner, more powerful code for real projects |

### Part B: AI, Automation & Agents 🤖
| Topic | What you'll learn |
|---|---|
| Introduction to AI & n8n | What AI and agents are, and how automation works |
| n8n Fundamentals | Building automated workflows without heavy coding |
| AI Agent Workflows with n8n | Connecting AI models to workflows to create simple agents |
| Prompt Engineering | Writing prompts that get clear, useful answers from AI |
| Context Engineering + Spec-Driven Development | Giving AI the right information and clear specs to build from |
| Claude Code Fundamentals | Using an AI coding assistant to write and fix code |
| Claude Code Advanced | Skills, Sub-agents & Plugins |
| 🏁 First Agent Build & Project | Putting it all together in your first agent |

## 🎯 By the End of This Module, You Will Be Able To

- ✅ Write and run Python programs with confidence
- ✅ Automate tasks with n8n workflows
- ✅ Write effective prompts and give AI the right context
- ✅ Use Claude Code to build faster
- ✅ **Build your very first AI agent** 🎉
